# Architecture Decision Records

Este directorio registra decisiones arquitectónicas relevantes y duraderas para que su contexto no dependa del historial del chat.

## Convención

Nombrar cada ADR como `NNNN-titulo-breve.md`, por ejemplo `0001-tenant-context-resolution.md`.

Cada ADR debe incluir:

- estado: proposed, accepted, superseded o deprecated;
- fecha;
- contexto y problema;
- opciones consideradas;
- decisión;
- consecuencias y trade-offs;
- referencias relacionadas.

No usar ADRs para detalles triviales o temporales. Si una decisión cambia, conservar el documento anterior y enlazar el ADR que lo reemplaza.
