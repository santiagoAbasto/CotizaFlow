# Visión de CotizaFlow

## Problema

Empresas B2B administran ventas mediante WhatsApp, Excel, PDFs, listas de precios, catálogos, vendedores, presupuestos manuales y seguimientos que se olvidan. La información queda fragmentada, responder toma demasiado tiempo y los errores erosionan margen y confianza.

## Flujo principal

cliente → consulta → interpretación → producto → compatibilidad → stock → proveedor → costo → lista de precios → descuento → margen → precio → cotización → PDF → envío → seguimiento → pedido → postventa

CotizaFlow debe dar continuidad y trazabilidad a este flujo completo sin convertir cada etapa en una herramienta aislada.

## Propuesta

CotizaFlow no es un CRM genérico. Es un **Operating System de cotización y ventas B2B** que organiza conocimiento comercial, aplica reglas determinísticas y ayuda al equipo a responder y dar seguimiento.

Cada capacidad debe vender más, reducir trabajo manual o errores, acelerar la respuesta, recuperar oportunidades, proteger margen, aumentar trazabilidad o producir información útil. Lo demás permanece en backlog.

## North Star

Reducir:

- tiempo de cotización;
- errores operativos y financieros;
- oportunidades olvidadas.

Aumentar:

- velocidad de respuesta;
- conversión;
- margen;
- trazabilidad.

El progreso comercial se mide primero por clientes fundadores, activación, retención y MRR, no por volumen de features.
