# Scorecard de validación

| Métrica | Meta inicial |
| --- | --- |
| Prospectos identificados | 100 |
| Conversaciones | 30 |
| Demos | 10 |
| Founding customers pagos | 3 |
| MRR comprometido | Registrar por moneda/contrato |
| Setup revenue | Registrar separado |

Para cada prospecto registrar: vertical, volumen de cotizaciones, proceso actual, dolor 1–5, dolor de seguimiento 1–5, precios 1–5, decisor, precio conversado, disposición a pagar, demo, siguiente paso y resultado. Leads reales viven fuera de Git.

Estados del pipeline fuera de CotizaFlow: `identified` → `contacted` → `replied` → `qualified` → `demo_scheduled` → `demo_completed` → `proposal` → `won` | `lost`.

Después de 30 conversaciones calificadas, si no hay dolor repetido ni disposición a pagar, revisar ICP y positioning antes de construir features.
