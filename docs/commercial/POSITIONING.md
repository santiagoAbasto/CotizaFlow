# Positioning

**CotizaFlow es el sistema operativo de cotizaciones para distribuidores y empresas B2B.**

Promesa: **Cotiza más rápido y evita perder ventas por falta de seguimiento.**

No vender como CRM genérico. El problema visible es: consulta → búsqueda/precio → PDF/Excel → envío → olvido. CotizaFlow mantiene cliente, productos, precio, cotización, PDF, seguimiento y prioridades en un único flujo.

Mensaje central: “No dejes dinero olvidado en cotizaciones que nadie volvió a llamar.”

## Copy para landing mínima

**Hero:** Cotiza más rápido. Da seguimiento. Cierra más ventas.

**Apoyo:** CotizaFlow organiza clientes, productos, precios, cotizaciones y seguimientos en un solo flujo para equipos comerciales B2B.

Estructura: problema → cómo funciona → cotización en minutos → seguimiento → dashboard → para quién es → **Solicitar demo**. No construir el sitio durante esta fase sin evidencia de que es el cuello de botella.
