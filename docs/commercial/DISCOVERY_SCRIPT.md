# Discovery

Abrir con: “Quiero entender cómo cotizan hoy, no mostrarte software todavía.”

- ¿Cuántas cotizaciones hacen por semana?
- ¿Cómo se prepara una cotización normal y dónde se consultan precios?
- ¿Quién define descuentos?
- ¿Cómo saben qué cotizaciones seguir y cuántas se pierden por falta de contacto?
- ¿Cuánto tarda una cotización normal?
- ¿Trabajan con listas diferentes? ¿Quién conoce hoy el pipeline?
- ¿Cuándo fue la última venta perdida porque nadie volvió a contactar?

Cerrar con problema, impacto, proceso de compra y precio: “¿Quién decide y qué tendría que pasar para que paguen por resolver esto?”
